# WebDAV 数据同步

入口：设置 → 数据同步 → WebDAV 同步。它与设备间的服务端 / 客户端同步分别启用。

1. 填写 WebDAV 服务器地址、用户名、密码（或应用专用密码）和相对目录。默认目录是 `lx-music`；服务器地址应指向已存在的 WebDAV 根目录，子目录会自动创建。
2. 保存配置并测试连接。测试会创建、读取并删除一个随机命名的临时文件，验证读写权限。
3. 启用 WebDAV，分别开启需要同步的项目。
4. 首次使用可在有数据的设备上选择“上传到云端”，然后在另一台设备上选择“从云端下载”。之后使用“立即同步”，或开启自动同步。

| 项目 | 同步内容 |
| --- | --- |
| 歌单 | 试听列表、我的收藏、自建及收藏歌单的名称、来源、歌曲和顺序；不包括临时列表 |
| 下载历史 | 已完成记录；不传输音乐文件 |
| 下载任务 | 未完成任务的歌曲、音质、文件名；恢复后暂停，开始下载时重新获取地址 |
| 系统设置 | 播放、界面、歌词、下载行为等常规设置 |
| 不喜欢列表 | 不喜欢规则 |

每项独立开关。关闭某项会停止该项双向同步，保留本机和云端已有内容。WebDAV 连接信息、设备同步配置、平台 Cookie、代理、OpenAPI 配置、本机下载路径、音频设备及自定义音源选择等本机配置不会随系统设置同步。快捷键、自定义音源文件、自定义主题文件和音乐文件不包含在同步快照中。

自动同步在应用完成启动后、重新启用或修改连接配置后约 10 秒执行首次检查，之后按所设间隔运行，默认 5 分钟，可设 1–1440 分钟。离开设置页仍会同步，退出应用后停止。离线时跳过检查，恢复联网后重新安排。

同步按项目比较上次成功同步的本机和云端内容。只有一端修改时传递该端数据；两端都修改了同一项时停止本次同步并显示冲突。首次同步时，本机该项为空会接收云端内容，两端已有不同内容则需选择上传或下载。上传 / 下载按钮会确认覆盖范围。云端缺少选中的项目时，下载会提示缺失项，避免把本地数据清空。

同步下载数据前需暂停下载。恢复过程中暂停新增、启动和删除任务，写入完成后刷新下载页面。原有完成记录的本机路径可以保留；从其他设备导入的历史仅是记录，需要另行取得音乐文件。两个下载分类的开关不一致时，已有的未选中分类记录优先保留；同时导入两个分类且出现相同任务 ID 时，完成记录优先。

云端文件是所选目录下的 `lx-music-sync.json`，当前格式版本为 1，单个文件最多 32 MiB。连接支持 HTTP / HTTPS 和 Basic 认证，HTTPS 使用正常证书验证。请求在主进程执行，不受浏览器 CORS 限制；使用直接连接，不套用音乐请求的代理。

替换本机数据前，在应用数据目录保留 `webdav-local-backup.json`，包含本次被替换的项目，下载记录包含原本机路径。它只保留最近一次覆盖前的副本。`webdav.json` 保存当前目标的同步基线与上次结果。备份和基线都留在本机。

目录操作使用 [WebDAV 的 PROPFIND、MKCOL、GET、PUT 和 DELETE](https://www.rfc-editor.org/rfc/rfc4918.html)。上传时采用 [HTTP 条件请求](https://www.rfc-editor.org/rfc/rfc9110.html#name-conditional-requests)：新文件使用 `If-None-Match`，已有文件优先使用强 ETag 和 `If-Match`，没有强 ETag 时使用服务端提供的 `Last-Modified`。时间戳验证精度取决于服务器；两类验证信息均缺失时停止覆盖。跨站重定向会被拒绝，用户名和密码不会转发给其他站点。
